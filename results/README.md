# Retained Results

These directories contain immutable artifacts copied from completed experiments. Absolute paths embedded inside some JSON reports record the original execution machine; they are provenance fields, not paths used by the release scripts.

- `main/`: selected task configurations and held-out-test metrics.
- `rq2/`: component ablations and additional Reentrancy seed runs.
- `rq3/`: architectural sensitivity and computational-cost artifacts.

Model checkpoints and console logs are intentionally excluded. See `docs/RESULTS.md` for metric sources and the RQ2 seed note.
